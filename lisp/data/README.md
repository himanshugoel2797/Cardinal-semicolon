# lisp/data

Binary data blobs shipped in the initrd (under `./lisp/data/`) and read by Lisp
modules via `(initrd-file "./lisp/data/<name>")` (the `sys-initrd` capability).

## font8x16.bin

A classic VGA-style **8×16 bitmap font**: 256 glyphs × 16 bytes, one byte per
row (MSB = leftmost pixel), indexable directly by character code (glyph `N` lives
at byte offset `N*16`). ASCII 32–126 are populated; all other code points are
blank.

Generated by `scripts/gen-font.py`, which rasterizes **DejaVu Sans Mono** into the
8×16 cell. The DejaVu fonts are distributed under a free, embeddable license
(Bitstream Vera Fonts Copyright © 2003 Bitstream, Inc.; DejaVu changes © Bitstream
Vera contributors) that permits redistribution and embedding. Only the rendered
glyph bitmaps are vendored here, not the TTF.

Regenerate with:

```bash
python3 scripts/gen-font.py            # writes lisp/data/font8x16.bin
python3 scripts/gen-font.py --dump Ag@ # eyeball glyphs as ASCII art
```

The font loader (`lisp/lib/font.clp`) reads any file in this layout, so the font
can be swapped for another 8×16 blob.
